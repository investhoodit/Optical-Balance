Optimal Balance Spa Website

Included:
- Responsive landing page
- Services catalogue with treatment prices
- Product shop catalogue
- Cart and WhatsApp checkout
- Booking form linked to WhatsApp
- Corporate wellness section
- PWA manifest and service worker starter files

How to use:
1. Open index.html in a browser to preview.
2. Upload the folder to hosting such as cPanel, Netlify, Vercel, or GitHub Pages.
3. Update WhatsApp number, services, prices and products inside app.js if needed.

Brand styling used:
Gold #D4AF37, White #FFFFFF, Soft Beige #E8DCC8, Soft Pink #F5D6D9, Charcoal Black #2B2B2B.
Fonts: Cormorant Garamond / Montserrat.
