# Optimal Balance Spa Website

Responsive website for Optimal Balance Spa in Mamelodi, Pretoria.

Included:
- Landing page
- Spa services and treatment prices
- Product shop catalogue
- Cart and WhatsApp checkout
- Booking form linked to WhatsApp
- Corporate wellness section
- Mobile-friendly styling

Deployment:
1. Go to repository **Settings**.
2. Open **Pages**.
3. Set source to **Deploy from a branch**.
4. Select branch **main** and folder **/root**.
5. Save. The site will publish as a GitHub Pages website.
